# ADR-012：演示部署与访问保护

- 日期：2026-11-09
- 状态：已实现，本机实际容器验收通过；公网部署待进行

## 目标

将求职展示项目部署到用户自己的服务器，电脑关闭后仍可访问。只使用模拟业务资料；不将其描述为正式企业生产系统。当前任务准备配置和验证，不购买服务器、不发布公网。

## 方案

浏览器通过 HTTPS 访问服务器上的 Caddy；Caddy 统一执行 Basic Auth，提供已构建的前端静态文件，将 `/api/*` 转发给同机 Docker 网络内的 FastAPI。后端不发布宿主机端口。SQLite、图片及模型配额账本使用独立持久化卷；业务单进程运行。

默认配置只绑定本机 127.0.0.1:8080，用于部署前验证；真实域名和公网端口由单独的覆盖配置启用。公网使用 Caddy 的标准证书管理，不能把本机 HTTP 测试配置直接开放到公网。

采用 Caddy 内置密码校验，保存 bcrypt 哈希，不新增自定义身份系统。用户输入演示密码后，浏览器同源请求复用认证。页面、API、图片、健康检查入口均受网关保护；容器内部健康检查不经网关。该访问口令不代表业务角色认证，所有演示访问者仍共享数据。

## 数据与费用边界

- 只有新空库自动建表、添加三名模拟维修人员；已有结构缺表或缺列则拒绝启动，需备份后另行迁移。
- 不复制本机业务数据库、图片或 `.env` 到镜像；不自动清空演示数据。
- 默认离线规则模式；显式选择 qwen 后才允许实际请求。
- 模型请求在供应商网络边界前申请持久化日配额和分钟配额，并限制单进程并发；失败请求也计数，账本不可用则回退。
- 配额计量单位是供应商请求次数，按 UTC 日/分钟窗口统计，不是费用金额，也不是业务工单数；费用需结合供应商账单控制。
- 飞书桥接继续保留原隔离本机入口，不在本轮改造为云端桥接，也不能直接连接持久化演示入口。

## 备选与取舍

- Nginx + 独立 TLS：可行，但本轮需要的鉴权、静态托管和证书管理可由 Caddy 统一完成。
- 自定义应用登录中间件：涉及自行实现安全边界，自动审批拒绝了未经验证的批量方案；改用标准网关能力，减少自定义鉴权代码。
- 内网穿透：适合临时联调，但依赖开发者电脑运行，不作为稳定求职展示部署。
- 托管数据库与多实例：当前数据量及展示范围不需要，先保持单实例、低并发；SQLite 和现有编号逻辑不支持据此宣称高并发。

## 验证要求

1. 临时库测试新库初始化、重启保留、旧结构拒绝及完整返工流程；不修改真实库。
2. 模拟供应商网络，验证日/分钟额度、并发、账本故障和清晰的规则回退，不发送付费请求。
3. 检查 Compose 插值、密码必填、后端端口隔离、构建上下文排除密钥。
4. 网关实际验证未认证401、错误口令401、正确口令访问页面/API/图片，并验证未知路径不能绕过保护。
5. 实际容器构建与公网 TLS 是独立验收项；没有可用 Docker 引擎/服务器时明确记录未验证，不将单元测试等同于已上线。

## 验证结果

后端290项、前端6项测试及构建通过；Docker实际镜像构建、Caddy鉴权、完整返工流程和容器重启持久化均通过。未进行真实公网发布或付费模型调用。完整证据见[部署验证](../verification/20261109-演示部署准备.md)。
