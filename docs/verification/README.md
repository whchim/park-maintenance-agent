`backend/scripts/verify_agents.py` 使用固定模拟报修、模拟人员和任务数，只检查 Agent 建议，不连接业务数据库，不创建客户、工单或分派。

从项目根目录运行，默认强制离线，不消耗模型调用：

```powershell
& .\.venv\Scripts\python.exe backend\scripts\verify_agents.py
```

需要验收真实模型时，先在本机 `backend/.env` 配置百炼 Key、官方入口和模型。显式执行下列命令会只在当前 PowerShell 进程启用千问，不修改配置文件；如需应用页面也使用千问，仍需将 `.env` 中 `PARK_AI_MODE` 改为 `qwen` 并重启后端。

```powershell
$env:PARK_AI_MODE='qwen'
& .\.venv\Scripts\python.exe backend\scripts\verify_agents.py --online --output docs\verification\online-local.json
```

最多 5 次模型请求：企服缺项、企服补充完整、工程最多3次决策。每个请求沿用模型超时配置，失败立即停止，无失败自动重试。`--output` 只允许创建新的 JSON 文件，重新运行请换报告名。报告包含固定模拟文本、输出、原文依据和执行轨迹，不包含密钥。

| 状态 / 退出码 | 含义 |
| --- | --- |
| `offline_checks_passed` / 0 | 离线规则和流程分支符合预期，不代表在线模型成功 |
| `online_checks_passed` / 0 | 本次固定用例全部由真实模型完成且通过结构、证据和人工门禁检查，仍需人工评估语义质量 |
| `checks_failed` / 1 | 某个用例未满足要求；规则回退也属于在线未通过，后续请求停止 |
| `configuration_not_ready` / 2 | 配置未启用或缺失，未发起模型请求 |
| `unexpected_error` / 1 | 验收程序发生意外错误，未输出可能含配置的原始异常 |
| `report_write_failed` / 1 | 检查已结束，但报告路径不可写；不会自动重新调用模型 |

本命令不测试 FastAPI、前端、数据库状态流转、原生图检查点或真实组织资料。企服两轮使用固定组合对话，不等于验证数据库中的跨请求续办；后者由独立内存数据库集成测试覆盖。

负责人看报告时重点核对：位置和故障是否来自原文；缺位置时有没有追问；补齐后是否等待人工确认；工程有没有实际查询目录；推荐理由有没有声称未查询的负载、值班或资料。`human_review_required=true` 表示自动检查通过仍不能代替业务核对。
