# 真实千问页面联调与演示（2026-11-01）

## 启动与隔离

本轮演示使用独立内存数据库，复用业务 API、Service 和 Agent；只预置三名明确标记的模拟工程人员，不导入现有业务资料。停止或重启后端后，演示数据清空。未执行现有数据库迁移、重建或删除，未修改本机 `.env`。选型依据见 [ADR-002](../architecture/ADR-002-演示环境隔离.md)。

终端一：

```powershell
Set-Location 'D:\桌面\park-maintenance-agent\backend'
& ..\.venv\Scripts\python.exe scripts\run_demo.py --online --port 8001
```

`--online` 显式启用真实千问，仅影响本次进程，使用本机已有百炼配置并消耗账号额度。只输入模拟资料。去掉 `--online` 则强制规则模式；启动器不因恰好存在密钥而自动联网。固定监听本机地址、单进程运行，不添加 reload 或多 worker。

终端二：

```powershell
Set-Location 'D:\桌面\park-maintenance-agent\frontend'
$env:API_PROXY_TARGET='http://127.0.0.1:8001'
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

打开 <http://127.0.0.1:5174/>，顶部应显示隔离演示提示。如果端口已有本轮服务，请直接使用；需要重新启动时只停止对应演示进程。不要为演示停止不相关服务。普通业务入口仍使用原来的启动方式。
